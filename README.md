# Day-Night Cycle of a City (2D Graphics)

A 2D computer-graphics project built in **C++ with OpenGL/GLUT** (CodeBlocks), simulating a day-to-night cycle over an animated city scene with boats, moving vehicles, speed control, and ambient sound effects.

## Features
- Animated city scene with a smooth day-to-night transition
- Boat animation with speed-control functionality
- Ambient sound assets (traffic, doors, night)

## Tech Stack
- C++ / OpenGL / GLUT (freeglut)
- CodeBlocks project (`.cbp`)

## Build & Run
1. Open the `.cbp` file in CodeBlocks with a GLUT/freeglut setup.
2. Build and run; keep the `.wav` assets alongside the executable.
